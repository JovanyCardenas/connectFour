
# Connect Four Game

This is a connect four game where there are 2 players who compete with each other, one player is 'O' and the other player is 'X'. You keep playing until there is 4 connecting sections that are either horizontal, vertical, or diagonal.
* 6 x 7 grid with 42 possible slots
